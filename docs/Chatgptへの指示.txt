# 前提 
- 添付画像が完成イメージです（できる限りピクセルパーフェクトを目指す）  
- レシポンシブ対応のため、PCの画像とスマートフォン向けの画像を用意しています。
- 添付の Assets.zip に画像素材が入っています。コードからは ./assets/ 配下を参照してください 
- 文字・余白・色・配置は、画像にできる限り合わせてください 
 
# 技術要件 
- HTML / CSS /javaScript 
- ファイル構成: index.html / css/style.css / assets/（画像） 
- セマンティックなHTML（header / section / footer など） 
- 文字コードは UTF-8、日本語フォントは Noto Sans JP を読み込む 
- index.htmlには以下のタグを入れること
　<meta name="robots" content="noindex, nofollow">
- footerに以下のタグをいれること
<p>本サイトは職業訓練の学習用に制作した架空のサンプルサイトです。
掲載している医院・人物・連絡先・所在地はすべて架空であり、実在のものとは関係ありません。</p>
- <head> の中に <meta name="robots" content="noindex, nofollow"> を入れる
- フッターに次の断り書きを入れる：本サイトは職業訓練の学習用に制作した架空の
  サンプルサイトです。掲載している医院・人物・連絡先・所在地はすべて架空であり、
  実在のものとは関係ありません。
